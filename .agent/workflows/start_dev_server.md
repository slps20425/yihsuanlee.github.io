---
description: Start the local development server (Vite)
---
Since the project uses **TypeScript** and **ES Modules** (import/export), you cannot run it by double-clicking the HTML files. You must start a local server.

1. Open your terminal.
2. Run the following command:
// turbo
   ```bash
   npx vite
   ```
3. Click the link shown in the terminal (usually `http://localhost:5173`) to open the app.
